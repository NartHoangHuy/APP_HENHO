# 📱 Flutter Dating App - HeartBeat

Ứng dụng hẹn hò giống Tinder được xây dựng bằng **Flutter** + **Django** + **MySQL** + **Firebase Realtime Database**.

[Xem nội dung đầy đủ trong README.md của app_henho]

## 📦 Cài đặt nhanh

### Flutter App:
```bash
cd app_henho
flutter pub get
flutterfire configure
flutter run
```

### Django Backend:
```bash
cd backend_project
python manage.py makemigrations
python manage.py migrate
python manage.py runserver 0.0.0.0:8000
```
